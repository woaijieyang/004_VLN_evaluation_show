# process-show 新手使用

1. 运行总目录与你系统对应的入口，等待本机选择页打开。
2. 在“选择测评”弹窗按日期、模型、数据集、完成条数选择；过期且无保留内容的运行不显示。
3. 在独立测评页面选Episode，拖动进度条或点击动作序列。
4. 用“保存到…”选择保留在运行目录，或下载到本机。
5. 在“保留设置”调整缓存时长；默认1小时，可自定义1分钟至30天。
6. 停止时使用页面按钮或入口菜单；关闭浏览器不等于停止后台。

如果缺少依赖，入口仅为本目录准备专用环境。没有任务时，检查本目录是否已有受支持的trace或SDK记录；不能从只有成绩的文件恢复完整回放。

目录范围、端口、缺图、BEV和常见问题详见 [README](README.md)。
